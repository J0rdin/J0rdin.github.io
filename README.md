# Jordin Johns — Game Artist Portfolio

A responsive, multi-page portfolio website built with HTML, CSS and vanilla JavaScript. Designed around a bold red / black / white editorial identity inspired by the visual reference shared in the project brief.

## Pages
- `index.html` — Home, About, Profile, selected work, experience and Contact
- `projects.html` — searchable-by-category project archive with filters
- `project.html?id=...` — reusable project case-study page with image lightbox

## Run locally
No build tools or package installation are required.
- Open `index.html` directly in a browser, or
- Run a local server from this folder: `python -m http.server 8000`
- Visit `http://localhost:8000`

## Deploy to GitHub Pages
1. Create a new GitHub repository.
2. Upload the contents of this folder (keep `index.html` at the repository root).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. GitHub Pages will publish the site at the repository URL.
